# 인간 존재에 대한 물리학적 가설 — v2

- **버전**: v2 (측정 #1~#4 편입, 핵심 명제 재확정)
- **날짜**: 2026-07-17
- **선행 문서**: [hypothesis-v1.md](./hypothesis-v1.md) (채록 + 비판). v2는 v1을 폐기하지 않고 **갱신**한다.
- **상태**: 부분 검증 / 부분 반증 / 반증 절차 가동 중
- **한 줄 요약**: **"인류 총체는 에너지 소산율을 시간에 따라 키우는 방향으로 조직된다. 이 가속의 주어는 부유한 개인이 아니라, 소비처를 옮겨가며 지속되는 인류 시스템이다."**

> v1은 "존재 이유"라는 목적론(H1)과 은유(H5, H10)를 걷어내는 문서였다. v2는 그 뒤 4개의 실측(측정 #1~#4)을 반영해 **명제를 좁히고, 무엇이 반증됐는지 기록**한다. 여전히 가설을 확증하지 않는다.

## 1. 핵심 명제 (재확정)

- **P0″ (주 명제)**: 인류 총체는 단위 시간당 에너지 소산율을 시간에 따라 증가시키는 방향으로 조직된다. **이 가속의 주어는 개별 인간·개별 국가가 아니라, 소비처를 이동시키며 지속되는 인류 시스템 전체다.**
- **P1**: 인간은 최소 대사 에너지로 그보다 훨씬 큰 외부 에너지를 소산시킨다(도구·기계·연산). — 측정 #1로 예시.
- **P2 (수정)**: ~~모든 인간 활동이 시간에 따라 더 많은 에너지를 소비한다~~ → **성숙한 소비처는 정체·탈동조화하지만, 신흥 소비처와 새 소비처(연산·AI)가 그것을 덮고도 남아 총체는 계속 가속한다.** — 측정 #2·#3·#4.
- **P5 (폐기된 순진한 형태)**: ~~부유할수록 개인·국가가 더 빠르게 더 많이 태운다~~ → **거짓**(측정 #2·#3). 대체: **P5′ — 부는 소산의 장소를 이동시킬 뿐 총량을 줄이지 않는다**(측정 #4).
- **P6 (신설, 이동 원리)**: 에너지 소산의 가속은 한 장소에 고정되지 않고 **이동**한다 — 성숙 경제 → 따라잡는 경제, 낡은 소비처 → 새 소비처. 겉보기 탈동조화는 종종 이 이동의 국지적 그림자다.

> **폐기된 것**: v1의 P0("존재 이유")·목적론 문장 전부. "왜 존재하는가"는 이 문서의 주장에서 제외한다.

## 2. 물리학적 전제 (상태 갱신)

1. 열역학 제2법칙 — 확립. (단 인간을 구별 못 함, H3.)
2. 비평형 소산 구조(Prigogine) — 확립.
3. **소산율 극대화 경향(MEPP)** — **여전히 논쟁적·미확립.** P0″의 아킬레스건. 측정은 "가속한다"는 경향을 지지하나, 그것이 *극대화 법칙*인지는 미결.
4. 생명·문명은 소산 구조 — 성립.
5. 누적 기술의 지수적 소비 증가 — **부분 확립**: 측정 #1(AI 전력 지수적), 측정 #3(세계 총량 2배). 단 성숙 경제에서는 성립 안 함(측정 #2·#3).
6. ~~욕망의 물리화~~ → **측정 대리변수로 대체 완료.** 욕망 대신 전력(TWh)·CO₂(Gt)로 명제를 다시 썼다(H5 해소).

**측정 #1 ↔ #3 잠금**: 미국 15년 전력 정체를 2024년에 깨는 게 데이터센터 → "가속은 사라지지 않고 새 소비처로 이동"의 직접 증거.

## 4. 반박 가능한 지점 (갱신)

- **R1 (MEPP)**: 비평형계가 소산을 극대화하지 않는 반례가 축적되면 전제 3이 무너진다. — 미해결.
- **R2 (탈동조화)**: **부분 판정 완료.** 성숙 경제는 1인당·총량 모두 감소(측정 #2·#3) → "모든 인간이 항상 가속"은 반증. 그러나 세계 총량은 상승(측정 #3)하고 감소분 일부는 오프쇼어링(측정 #4) → **총체 명제 P0″는 생존.** R2는 P5를 죽였고 P0″는 살렸다.
- **R3 (효율의 절대 감소)**: 세계 **총** 에너지가 반등 없이 장기 절대 감소하면 P0″ 반증. — 아직 미발생(측정 #3).
- **R6 (이동 원리 반증)**: 새 소비처(AI 등)가 등장하지 않고, 성숙 경제 정체가 신흥국 성장으로도 상쇄되지 않아 **세계 총량이 꺾이면** P6·P0″ 동시 반증. — 감시 지표.
- **핵심 정식 예측(측정 #1)**: 가속 국면 유지 시 2027 데이터센터 전력 ≈ 631 TWh. 2027 ≤ 2026 수준이면 그 대리변수에서 가속 반증.

## 5. 기존 이론과의 차이 (갱신)

**소산·복잡성 축(P0″·P1)** — v1과 동일: **Chaisson(energy rate density)**, **England(소산 주도 적응)**, **Prigogine**, **Kardashev**, **Lotka–Odum(최대 출력)**, **MEPP**. 방어 가능한 핵심은 대부분 여기서 재발명됐다. 아직 이 축에서 독창적 기여는 확립 안 됨.

**이동·재분배 축(P6, 태극 프레임)** — v2에서 추가 대조. 이 축은 물리학이 아니라 **역사·경제 순환론**의 재발명이다:
- **Giovanni Arrighi**(축적의 체계적 순환), **George Modelski**(장주기), **Peter Turchin(cliodynamics)** — "역사의 물리학화"의 실제 학문판, **필독**.
- **Kondratiev 장파**, **Schumpeter 창조적 파괴**.
→ 태극/부의 이동 자체는 물리 가설이 아니다. 물리로 살릴 수 있는 유일한 조각은 **측정 #4**(소산의 공간 이동, ~6–8 Gt/년)뿐이며, 그것만 본문(P6)에 편입했다. 나머지는 [notes/](./notes/taiji-wealth-migration.md)로 분리.

## 6. 반증된 것 vs 살아남은 것 (정직한 점수판)

| 명제 | 판정 | 근거 |
|---|---|---|
| P0(존재 이유·목적론) | **폐기** | H1 (물리학은 목적을 발화 못 함) |
| P5(부유한 개인·국가 = 더 태움) | **반증** | 측정 #2·#3 |
| P2(모든 활동 항상 증가) | **반증→수정** | 측정 #2·#3 (성숙 경제 정체) |
| P0″(인류 총체 소산 가속) | **생존** | 측정 #3 (세계 총량 2배), #1 (AI 폭증) |
| P6(소산의 이동) | **지지** | 측정 #4 (오프쇼어링), #1↔#3 (새 소비처) |

**요지**: 가설은 개인·국가 수준에서 반증됐고, 총체 수준에서 살아남았다. 다 맞았으면 그것이 H2(반증불가)의 증거였을 것 — **일부가 반증됐다는 것이 이 가설이 비로소 과학이 됐다는 신호다.**
